Getting Started

What FFmpeg Studio is and the one idea that runs through every page.

FFmpeg Studio is a graphical frontend for FFmpeg. Every page follows the same shape: pick input(s), set options, review the exact FFmpeg command it's about to run, then click Run. Nothing here hides what's actually happening — if you know FFmpeg, you can always see and copy the real command; if you don't, the options are labeled in plain language.

Keyboard shortcuts

  • F1 — open this Help page
  • Ctrl+, — jump straight to Settings
  • Ctrl+Q — quit the app

The pattern every page shares

  • Select input — via a file dialog or drag-and-drop.
  • Set options — the command preview box updates live as you change them.
  • Run — FFmpeg runs in the background; the app stays responsive, and you get a progress bar with time/speed/ETA.
  • Done — the output is saved next to your input by default (or wherever you typed in the Output name field), logged to History, and the folder opens automatically if you've turned that on in Settings.

Before anything else: FFmpeg has to be found

See FFmpeg Setup — nothing else works until the Home page shows a green "FFmpeg detected."

FFmpeg Setup

How the app finds ffmpeg.exe and ffprobe.exe, and what to do if it can't.

FFmpeg Studio looks for FFmpeg in this order, and uses the first one it finds:

  1. A path you set manually in Settings → FFmpeg.
  2. A bundled copy — an ffmpeg/ folder containing ffmpeg.exe and ffprobe.exe sitting next to the app itself.
  3. Your system PATH — if FFmpeg is installed normally (e.g. via winget install ffmpeg), this is usually what gets used.

If Home shows "✗ FFmpeg not detected": install FFmpeg (or confirm it's on PATH), then click Detect Automatically in Settings — or just Browse… directly to your ffmpeg.exe and ffprobe.exe.

ffprobe (which ships alongside ffmpeg) is used constantly behind the scenes — it's how the app reads a file's real duration, resolution, codec, and bitrate instead of guessing from the file extension.

Compress

Shrink a video's file size. Codec, CRF, preset, resolution, and audio, all in plain terms.

Pick a video and the app immediately reads its real duration/resolution/codec via ffprobe, so the info line above the options is always accurate, not a guess from the filename.

The options, in practice

  • Codec — H.264 is the safe, universally-compatible default. H.265 gives smaller files at the same quality but takes longer to encode and isn't supported everywhere. AV1 is smaller still but slower and less compatible.
  • CRF — the main quality/size knob. Lower = higher quality, bigger file. 18–23 is visually lossless to "very good" for most content; 28+ starts showing compression artifacts. There's no "correct" number — it depends on the source and your tolerance for file size.
  • Preset — how hard the encoder works to compress efficiently. Slower presets produce smaller files at the same CRF, at the cost of encoding time. medium is a reasonable default; drop to fast if you're encoding a lot of files and don't need the last few percent of compression.
  • Resolution — downscaling (e.g. 1080p → 720p) is one of the most effective ways to shrink a file, often more impactful than tweaking CRF.
  • Audio — "copy" keeps the original audio stream untouched (fast, no quality loss, but no size savings on the audio track). Re-encoding to AAC at a lower bitrate saves more space if the audio track is a meaningful chunk of the file.

The Output name field is optional — leave it blank and you get yourfile_compressed.mp4 automatically.

Convert

Change container/codec — MP4, MKV, MOV, AVI, WebM — with friendly quality presets or full manual control.

Use this when you need a specific container or codec rather than just a smaller file — e.g. converting a .mov from a phone into a .mp4 that's more universally playable, or re-encoding into VP9/AV1 for web delivery.

Quality presets

"Very High / High / Medium / Low" map to sensible CRF values (18/20/23/28) behind the scenes — pick one of these unless you specifically need a custom CRF or target bitrate. Choosing copy for either codec skips re-encoding that stream entirely — instant and lossless, but only works if the target container actually supports the source codec (e.g. you generally can't copy H.265 video into an old-style AVI).

Trim / Cut

Cut a clip out of a video by start time and either an end time or a duration.

Enter a Start time and either an End time or a Duration (whichever is easier to think about for what you're cutting) — HH:MM:SS or HH:MM:SS.milliseconds.

Fast vs. Accurate — this matters

  • Fast — copies the video/audio streams without re-encoding. Nearly instant, but the actual cut can only land on the nearest keyframe, so your clip's start might be off by up to a second or two depending on the source's keyframe interval.
  • Accurate — re-encodes the clip, so the cut lands exactly where you asked. Takes real encoding time, scaling with clip length.

Rule of thumb: try Fast first. If the start of your clip looks off, switch to Accurate.

Merge / Concatenate

Join multiple videos into one, in whatever order you arrange them.

Add videos, then use Move Up/Move Down to set the order they'll play in the final file.

Fast vs. Compatibility

  • Fast — concatenates without re-encoding. Very quick, but only works reliably when every clip shares the same codec, resolution, and frame rate — e.g. several clips exported from the same camera or the same editing project.
  • Compatibility — re-encodes everything to a common resolution/frame rate first, so it works even when your clips differ (a phone clip plus a screen recording plus a downloaded video, for instance). Slower, since every clip gets re-encoded.

If Fast mode produces a broken or out-of-sync result, that's the signal your clips aren't actually compatible — switch to Compatibility mode.

Audio Tools

Three tabs: pull audio out of a video, convert an audio file, or merge many audio files in order.

Extract from Video

Pulls just the audio track out of a video file — useful for turning a recorded lecture or interview into a podcast-style audio file. Choose the output format and, for lossy formats, a bitrate. Pick copy as the format to skip re-encoding entirely: the original audio codec is pulled out byte-for-byte, saved as a .mka file (a container that can hold essentially any audio codec) — fastest possible option and zero quality loss, at the cost of not being able to choose a bitrate or sample rate since nothing is being re-encoded.

Convert

Changes an audio file's format, bitrate, and/or sample rate. "Keep original" for sample rate leaves it untouched; picking 44100 or 48000 forces a specific rate. As with Extract, choosing copy as the format remuxes the file without touching the audio at all (saved as .mka) — useful when you just want a different container, not a different encode.

Merge (Batch)

This is built specifically for the "I have a folder of numbered audio clips and want them joined in order" workflow. Select the folder and the app automatically detects every audio file in it and sorts them naturally — meaning 1.mp3, 2.mp3, 3.mp3, … 10.mp3, 11.mp3, not the lexicographic (alphabetical) order a plain file listing would give you, which would incorrectly put 10.mp3 right after 1.mp3. Reorder manually afterward if you need something other than the natural-sort order.

Images → Video

Turn a sequence of images into a video, with a uniform duration per image and optional audio.

Add images, use Natural Sort to put them in numeric order (same logic as Audio Merge — img2.jpg before img10.jpg), and set how long each one displays. Every image gets the same duration here — if you need different images to show for different lengths of time (e.g. to sync against a voiceover), that's what the Storyboard page is for.

Fit modes

  • Fit / Pad — the whole image is visible, with black bars filling any leftover space (letterboxing). Nothing gets cropped.
  • Crop — the image fills the entire frame, cropping whatever doesn't fit. No black bars, but edges of the image may be cut off.
  • Stretch — forces the image to the exact target size, ignoring its original aspect ratio. Fills the frame perfectly but distorts non-matching images.

Adding an audio track makes the video stop as soon as whichever of audio/images-sequence is shorter finishes (-shortest) — so if your images only add up to 30 seconds but the audio is 60, the video ends at 30s.

Video + Audio

Replace, add to, or strip a video's audio track.

Modes

  • Replace — the video's original audio is discarded entirely and swapped for your chosen audio file.
  • Add — your audio file is mixed together with the video's existing audio (both play at once), rather than replacing it.
  • Remove — strips all audio, no audio file needed.

Audio encoding (Replace mode)

When replacing audio, choose Copy (fastest, original codec) to attach your audio file exactly as-is with no re-encoding — the video is already stream-copied untouched in every mode here, so with Copy selected the whole operation just repackages both files with no quality loss and almost no processing time. Re-encode (AAC) converts the audio to AAC first, which is safer if your audio file's codec isn't one your target container/player supports well. Add mode always re-encodes regardless of this setting, since mixing two audio tracks together is a filtering operation that has to produce new audio data.

Duration handling

  • Shortest — stops as soon as the shorter of the two streams ends.
  • Loop audio — repeats your audio file end-to-end until the video ends, so a short music clip can cover a longer video without a silent gap at the end.
  • Video duration — matches the video's own length as the authoritative duration.

Storyboard: Audio + Images → Video

The most flexible option: match multiple audios to multiple images with explicit per-image timing, then merge the results.

Use this when Images → Video's "same duration for every image" isn't flexible enough — for example, syncing images to specific moments in a voiceover, or when different audio clips need different numbers of images (some audios might get 2 images, others just 1 — there's no fixed ratio).

The workflow, step by step

  1. Add your audios on the left panel — in whatever order you'll eventually want them to play in the final video (you can change this later).
  2. Click an audio to select it — its duration is shown, and the image-timing table on the right becomes active for that audio specifically.
  3. Add Image(s) to that audio. Each new image defaults to starting right where the previous one's End left off, with a 5-second duration — edit the Start and End columns directly to set exactly when each image should appear and disappear.
  4. Repeat for every audio. Some can have one image, others several — each audio's image list is independent.
  5. Generate Videos renders one video per audio (its image sequence plus that audio's own track). This runs as a queue, one audio at a time — if one audio has a problem, the rest still render.
  6. Once videos exist, the Final merge order list fills in automatically. Reorder it if the final video should play the pieces in a different order than the audio list above.
  7. Merge into Final Video concatenates everything into one file.

Tips

  • Auto-Fill to Audio End sets only the last image's End time to match the audio's full duration — a quick way to make sure there's no silent gap at the end without typing the exact number.
  • An image's End time must be after its Start time — the app checks this before rendering and tells you exactly which audio/image pair is the problem.
  • Rows are sorted by Start time automatically when generating, so it's fine to add images out of order and fix the times afterward.
  • The Audio encoding setting in Video Settings applies to every generated video: the video track always has to be freshly built from your images (there's no "original video" to copy), but the audio being attached doesn't need touching at all. Copy (fastest, original codec) attaches it exactly as-is; Re-encode (AAC) converts it first, which is the safer default if you're unsure your audio's codec plays back cleanly from an MP4 container.

YouTube Shorts

Convert landscape video to vertical 9:16 for Shorts, Reels, or TikTok.

Modes

  • Crop — fills the vertical frame completely by cropping the sides of the original video. No black bars, but you lose the edges of the frame.
  • Fit — keeps the entire original frame visible, adding black bars above and below to fill out the vertical space.
  • Blur — the best of both: your full video is shown centered, with the gaps filled by a blurred, zoomed-in copy of the same video instead of plain black bars.
  • Custom — set your own exact width/height instead of the standard 1080×1920.

Audio encoding

The video track always has to be re-encoded here — cropping, scaling, and the blur background are all applied through FFmpeg's video filter chain, which requires a full re-encode. The audio track is untouched by any of that, though, so Copy (fastest, original codec) is available to skip re-encoding the audio specifically — free speed with no quality loss, since nothing about the audio actually needs to change. Re-encode (AAC) (the default) re-encodes it anyway, which is the safer choice if you're not sure the source audio codec is broadly compatible.

Batch Processing

Apply Compress to many files or an entire folder at once.

Add individual files or an entire folder (only recognized video extensions are picked up automatically). The same compression settings are applied to every file. Files render one at a time; if one file fails, the rest of the batch still runs — check the per-file status icons (⏳ queued, ▶ running, ✓ done, ✗ failed) to see which ones need attention.

Every file's result — success or failure — is logged to History individually, so you can review exactly what happened after a large batch finishes.

Presets

Built-in and custom presets — browse, duplicate, export, and import.

Five built-in presets ship with the app: YouTube 1080p, YouTube Shorts, Lecture Compression, Small File, and High Quality. Select one to see its exact parameters listed on the right.

Built-in presets can't be edited or deleted, but you can Duplicate one to create an editable custom copy, or Export/Import presets as JSON files to back them up or share them.

History

Every completed job — date, operation, input, output, and status.

Every job that finishes (single-file or as part of a Batch/Storyboard run) is logged here automatically, including failures. Select an entry to Open Output Folder, Copy Command (the exact FFmpeg invocation that ran, for reuse or debugging), or delete individual entries. Clear All wipes the whole history.

Settings

FFmpeg paths, default output folder, theme, and behavior toggles.

  • FFmpeg / FFprobe executable — manually point at specific binaries, or click Detect Automatically to re-run the bundled → PATH → user-configured search.
  • Theme — Light, Dark, or System (follows your OS's color scheme where the OS reports one). Takes effect immediately.
  • Language — switches the app's interface language (English or Turkish, with more addable later). Takes full effect after restarting the app.
  • Overwrite existing files — controls what happens when an output file already exists: always overwrite, never (auto-renames instead), or ask every time.
  • Automatically open output folder — when on, the folder containing your finished file opens automatically the moment a job succeeds.

Troubleshooting

Common problems and where to look.

"FFmpeg not detected" — see FFmpeg Setup above.

A job fails with an error dialog — every page's log panel shows FFmpeg's actual stderr output, which almost always names the real problem (a codec that isn't available in your FFmpeg build, incompatible inputs for a fast-mode merge, a path FFmpeg couldn't write to, etc.). The error dialog itself also includes the last few lines of that log.

Merge or Storyboard's final merge looks wrong/out of sync — this is almost always a Fast-mode limitation with mismatched sources; switch Merge to Compatibility mode.

Settings aren't saving — settings live in %APPDATA%\FFmpegStudio\settings.json; make sure that location is writable.

Logs — a full rotating log file is written to %LOCALAPPDATA%\FFmpegStudio\Logs\ffmpeg_studio.log covering startup, FFmpeg detection, every command executed, and errors.
